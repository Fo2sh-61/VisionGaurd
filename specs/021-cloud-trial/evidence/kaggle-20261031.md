## `benchmark.py --site 16` (default mix), on the T4's machine

- One 8-core box carries about **38 cameras** of this mix; 16 cameras need
  3.32 cores flat out. The processor, not the GPU, is the limit here.
- Measured by the run: the person row and the capture split. Every other row is
  carried from earlier runs, as the tool itself says.

3. Admin created in the wrong database → `trial_env` for every tool (`21a664a`).
4. Stopping a notebook cell stopped the engine and the tunnel → `setsid` (`5260fd0`).
