## Format: `- [ ] T### [P?] [US?] [engine|console] Description with exact file path`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task).
- **[US1]** shared areas, **[US2]** zones, **[US3]** stations. Setup, Foundational and Polish carry no story label.
- **engine** = Python under `engine/`; **console** = TypeScript under `web/src` (and `mobile/src` for byte-shared files).

## Conventions that apply to every task

- Audit `self._log(...)` BEFORE the write. Permissions by path in `engine/vg/auth/deps.py` only, never a decorator. Wire types subclass `Wire`. Times through `_instant()`. `Fraction`/`Confidence` clamp 0..1. Degradation is payload, never a 5xx; `SubsystemUnavailable` is 503.
- Rule 2: `StationsWorker` holds no person id, body key or embedding between frames. Rule 3: station pictures and the editor pass `detections={false}`. Rule 9: no feature needs another switched on.
- CRLF: `engine/vg/api/*.py`, `web/src/services/*.ts`, `web/src/types.ts`, `STATUS.md` are CRLF. Use the Edit tool, then check `git diff --stat` for whole-file churn.
- Parity: files in `tools/check_parity.py` `PARITY_FILES` are edited in `web/src`, then copied byte for byte to `mobile/src` (only if the mobile copy was identical before), then `python tools/check_parity.py`.
- Python 3.10 compatible: `from __future__ import annotations`, no `match`, no `datetime.UTC`.
- While working run only the test files you touch; the full suite runs once in the Polish phase.
