# docs/prompts/

The feature descriptions handed to `$speckit-specify` to open a spec. They are
**inputs**, kept for provenance — the spec each one produced is the thing to
read, and the thing to plan from.

| Prompt | Produced |
|---|---|
| `P0-truthfulness.md` | the P0 truthfulness and safety-net work in `docs/PLAN.md` |
| `009-workload-placement.md` | `specs/009-workload-placement/` |
| `010-ask.md` | `specs/010-ask/` |

Never plan from a prompt. It records what was asked for, not what was decided.
